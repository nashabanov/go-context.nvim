*go-context.txt*  Per-workspace Go build tags for Neovim

==============================================================================
SETUP                                                        *go-context*
                                                             *go-context-setup*
Requires Neovim 0.10 or later. Enable commands and tag suggestions: >lua

    require("go_context").setup()
<
To apply saved tags when gopls starts, add this field to your existing gopls
configuration: >lua

    before_init = require("go_context").before_init,
<
The plugin does not install or start gopls. Context changes update running
gopls clients with a matching workspace root.

==============================================================================
COMMANDS                                                     *go-context-commands*

:GoContext                                                   *:GoContext*
        Open a tag input prompt prefilled with the current workspace tags.
        Submit an empty value to save an empty tag list. Cancel to leave the
        context unchanged.

:GoContext {tags}
        Replace the workspace tags with a comma- or space-separated list.
        Duplicate tags are removed while preserving order. Examples: >vim

            :GoContext integration,smoke
            :GoContext integration smoke
<
:GoContext!                                                  *:GoContext!*
:GoContextClear                                              *:GoContextClear*
        Clear the workspace tags, remove the saved context, and remove the
        -tags build flag from matching gopls clients. Other flags are preserved.

Commands use the current buffer's workspace. Its root is resolved from an
attached gopls client, or from a parent directory containing go.work or go.mod.
Contexts persist outside the repository under:

    stdpath("state")/go_context.nvim/

==============================================================================
TAG SUGGESTIONS                                               *go-context-suggestions*

Entering a *.go buffer checks //go:build directives before the package
declaration. New custom tags are offered through vim.ui.select.

Accepted tags are appended to the workspace context and saved. Declining or
dismissing a prompt suppresses those tags in that workspace for the rest of
the Neovim session. Other workspaces are unaffected.

GOOS/GOARCH values, unix, cgo, gc, gccgo, ignore, go1.<number> release tags,
and directly negated tags such as !enterprise are excluded. Boolean expressions
are not fully parsed: postgres || sqlite suggests both tags.

Only the current buffer is inspected. Legacy // +build directives and filename
constraints are not considered. Tags are never removed automatically.
